# MedAPP
### Intelligent Healthcare Appointment Booking Web App
A full-stack medical appointment web application with role-based authentication (Patient, Doctor, Admin), built with Spring Boot and Angular. Features include secure httpOnly based login, user registration, doctor/patient profiles, real-time availability management and a smart pre-visit form for patients.
